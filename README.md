# 🧮 Calculadora em Python

Projeto de calculadora em linha de comando desenvolvido durante meus estudos iniciais de Python.

## 🚀 Funcionalidades
- Operações básicas (+, -, *, /)
- Validação de divisão por zero
- Execução em loop até o usuário desejar sair

## 🛠️ Como executar
1. Tenha o Python instalado.
2. Execute o comando: `python main.py`
